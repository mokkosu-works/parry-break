# キャラ別動画 v05(5 人のプレイ紹介)

プロジェクト名は `<名前>-play`(2026-11-16 に `character-<名前>-v05` から改名)。

画面構成案 `character-layout-comparison-v01.png` の見た目に揃えた版。モード紹介(`shorts-modes.md`)も同じ作りで、画面構成は本人が 2026-11-16 に「これでいい」とした。

## 決めたこと

- **文字は画像にする。** 構成案の文字は画像生成が描いたもので、合うフォントがない。v02 は Noto Sans CJK で近づけたが「微妙に違う」と言われた。見出し・吹き出し・「ストアで検索」は Codex の画像生成で作った透過 PNG(`promo/assets/text/`)。文言を変えるときは画像を作り直す。
  - v04 で文字をテキスト(Mochiy Pop One)に戻したが、編集ツールでエラーが出て(原因は直した)、本人の判断で画像に戻した。文言は本人ではなく私が直す。
  - 画像生成は画数の多い漢字(撃、瞬)を崩した。生成した文字は 1 枚ずつ拡大して確かめ、崩れたら画数の少ない言い方に変える(「撃ち返す」→「打ち返す」、「当たる瞬間」→「パドルに当たる直前」)。
- **タイトルはゲームの Silkscreen の PARRY / BREAK。** 構成案のロゴは画像生成が描いたもので、ゲームのタイトルではない(v03 で使ったら「もともとのゲームタイトルが消えてる」と言われた)。
- **タグ**: 5 人ともゲーム画面の右下に「ステージ」のタグを付ける(モード紹介と同じ大きさ・位置)。アカネ・シズク・モモカのタグ(`<名前>_tag_stage.png`)は、ワカナのタグを各キャラの色に塗り替えて作った(Codex の画像は地の色にむらが出たため)。
- **キャラは全員左。** 構成案ではアカネとモモカが右だが、本人の指示で揃えた。モモカの吹き出しは、枠だけ左右反転して文字を戻した `momoka_v05_bubble_N_left.png`。
- **アウトロ**は、本人が編集ツールで調整したミツバ v05 の配置を型にする(アイコンとタイトルが上、キャラが左、右に吹き出し・「ストアで検索」・バッジ・クレジット。ゲーム映像なし)。声は 19 秒に「パリィブレイク。ストアで検索!」、21.5 秒からキャラの締めの一言。
- **置いてはいけない範囲**(1080×1920):
  - 上 130px、下 480px(y>1440)、左右 100px。
  - ショートの右のボタン列(実機で測って x>930、y>1220)。
  - キャラの絵(透明な余白を除く)は、ゲーム画面の枠・吹き出し・タイトル・「ストアで検索」に重ねない。高いポーズは縮める(`fit_character`)。
  - 確かめ方は `python3 promo/editor/check_layout.py <プロジェクト名>`。
- **v05 に残っている直し**: プレイ中のタイトルの右端が 950 で、ボタン列にかかる(モード紹介では 900 に直した)。入れるかは未定。

## 作り方

```sh
python3 promo/build/create_character_layout.py akane shizuku momoka wakana   # v02 から v05 を作る(既にあれば飛ばす)
python3 promo/editor/check_layout.py akane-play                     # 置いてはいけない範囲と重なりの確認
```

ミツバ v05 は本人が編集ツールで調整したので、作り直さない(作り直すと調整が消える)。

## 文字の画像の作り方

1. 構成案や前の素材を参考画像にして、Codex に頼む。
   `codex exec -c model_reasoning_effort="low" -s workspace-write --skip-git-repo-check "<指示>" -i 参考.png < /dev/null`
   - `-i` は複数ファイルを取るので、指示を先に書く。
   - 並行で何本も頼まない(利用上限で止まった。止まっても、生成済みの画像は `~/.codex/generated_images/` に残る)。
2. 生成した文字を拡大して確かめる。吹き出しの中にしみが出たら、枠の内側の文字以外を 1 色で塗り直す。
3. 透明な余白を詰め、8px の余白を足し、横 1000px までに縮め、256 色にして `promo/assets/text/shorts-play/<名前>_<版>_<種類>_<番号>.png`(モード紹介は `shorts-modes/`) に置く。

指示文は `codex/<回>/ref/`。元の生成画像と参考画像は `codex/<回>/out/` と `ref/` にあるが、大きいので git に入れていない(手元だけ)。

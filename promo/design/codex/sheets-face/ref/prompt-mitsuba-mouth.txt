Use case: identity-preserve
Asset type: 全身立ち絵の口パク素材(口の開閉の片方)。ショートと通常尺で共通に使う。
編集対象: mitsuba_sheet.png(ミツバの全身6ポーズを横1列に並べた透過シート、2172×724)。

このシートを編集し、6体それぞれの「口だけ」を反対の状態にした同じシートを1枚作る。並び順・各体の位置・大きさ・体の向き・手足・髪・リボン・服・目・眉・頬・汗や涙・効果線・線の太さ・塗り・配色は、元の絵から一切変えない。変えるのは口の形だけ。シート全体の大きさと横1列6体の並びも元と同じにする。

左から順に:
1. 通常(明るい笑顔、口を閉じた笑み) → 笑顔のまま、話している途中の自然に開いた口にする。
2. 集中(口を結んだ真剣な顔) → 真剣な顔のまま、短く話すように口を少し開ける。
3. 予想外(目を丸くして小さく「お」の口) → 驚いた顔のまま、口を閉じて小さくすぼめた口にする。
4. 失敗(眉を下げて涙、口を閉じている) → しょんぼりした顔のまま、「あっ」と言うように口を少し開ける。
5. 成功(目を閉じて大きく口を開けて笑う) → 目を閉じた満面の笑顔のまま、口を閉じた笑み(口角を上げた細い笑み)にする。
6. 固有(目を輝かせて口を開けた笑顔で指さし) → 目を輝かせたまま、口を閉じた笑み(口角を上げた細い笑み)にする。

開いた口は会話中の自然な大きさ(叫ぶほど大きくしない)。閉じた口は歯を見せない。
背景は実際のアルファ透明。背景色、床、影、文字、枠線、番号、透かし、ほかのキャラは入れない。チェック柄を描かない。

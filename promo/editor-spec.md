# 動画レイアウト編集ツール 仕様

## 目的

キャラクター紹介動画の画面構成を、コードを編集せずに試せるローカル編集ツールを作る。キャラクター、ゲーム映像、見出し、字幕、アプリアイコン、ストアバッジなどをプレビュー上で動かし、配置を保存して動画に書き出せるようにする。

## 方針

- PC上のブラウザーで使うローカルツールとする。外部サービスへのアップロードはしない。
- 編集対象はまずキャラクター主体の縦動画。キャンバスは1080×1920、プレビューは画面内に縮小表示する。
- 既存の素材と動画生成処理を再利用する。素材や音声・投稿記録を編集画面から変更・公開しない。
- 書き出し先は新しいファイル名にし、既存動画を上書きしない。
- 初版は画面配置を調整するMVPとし、音声編集、動画の細かなカット編集、投稿機能は対象外。

## 画面

### 上部ツールバー

- プロジェクト名
- 保存、元に戻す、やり直す
- プレビュー再生／停止
- 動画を書き出す
- 未保存状態の表示

### 左パネル

- シーン一覧：冒頭、パリィ、ブロック崩壊、アウトロ
- 選択中シーンのレイヤー一覧
- 追加できる要素：テキスト、キャラクター、アプリアイコン、App Store／Google Playバッジ
- 素材はリポジトリ内の既存ファイルから選ぶ。初版で任意ファイルのアップロードはしない。

### 中央プレビュー

- 縦長キャンバスを実際の比率で表示する。
- 要素をクリックして選択し、ドラッグで移動する。
- ハンドルをドラッグして拡大・縮小する。初版では縦横比を維持する。
- 重なり順をレイヤー一覧から変更する。
- セーフエリア（画面上端・下端のUIに隠れやすい領域）を切り替え表示する。
- 選択中シーンのゲーム映像を指定時刻で静止表示し、プレビュー再生中は動画とキャラクターの縦揺れを確認できる。

### 右パネル

選択要素に応じて編集項目を表示する。

- 共通：X、Y、幅、高さ、表示／非表示、重なり順
- テキスト：文言、フォント、サイズ、色、縁取り、行揃え
- 画像：素材、透明度
- ゲーム映像：素材動画、開始時刻、表示範囲
- キャラクター：ポーズ、サイズ、揺れの有無と振幅

数値入力でも位置とサイズを微調整できる。キャンバス上の移動と数値入力は即時にプレビューへ反映する。

## シーン操作

- シーンを選ぶと、そのシーンのレイアウトと素材を表示する。
- 各シーンに開始時刻と長さを表示する。初版ではシーンの順序と長さの変更は許可せず、既存の24秒構成を保つ。
- シーン間で共通の要素（ロゴ、キャラクターサイズなど）は「全シーンに適用」を選べる。
- キャラクターの揺れはシーン単位で切り替えられる。アウトロなど静止させたいシーンは個別にオフにできる。
- テキストやアイコン、ストアバッジは、追加・削除・複製できる。

## 保存形式

- レイアウトは `promo/editor/projects/` 以下のJSONに保存する。
- JSONにはシーン、素材への相対パス、各要素の位置・サイズ・表示状態・スタイル、動画の開始時刻を含める。
- 元素材は複製せず、リポジトリ内の相対パスで参照する。
- 不明な素材パスや不正な数値は保存・書き出し前にエラーとして表示する。

例：

```json
{
  "version": 1,
  "name": "character-promo",
  "canvas": { "width": 1080, "height": 1920 },
  "scenes": [
    {
      "id": "parry",
      "duration": 8,
      "video": {
        "src": "../../capture/raw/s4-7_sloppy_02.mp4",
        "start": 18
      },
      "layers": [
        {
          "id": "brand",
          "type": "text",
          "text": "PARRY\\nBREAK",
          "x": 485,
          "y": 1140,
          "width": 500,
          "fontSize": 82,
          "color": "#ffc61a"
        }
      ]
    }
  ]
}
```

## プレビューと書き出し

- プレビューは選択シーンの静止画をすぐ更新する。再生時はシーン内のゲーム映像、音、揺れを確認できる。
- 「動画を書き出す」で、保存済みレイアウトを既存の動画生成処理へ渡す。
- 書き出し中は進捗と失敗理由を表示する。VOICEVOXが必要な場合は、起動していないことを事前に知らせる。
- 完了後に動画の保存場所、尺、解像度を表示する。
- 書き出し名は自動採番し、既存ファイルがあれば別名にする。
- 書き出し後に、映像・音声の尺、1080×1920、クレジット表示を確認する。

## エラー表示

- 素材が見つからない、動画を読めない、フォントがない、VOICEVOXに接続できない、書き出しに失敗した場合は、原因と修正方法を画面に表示する。
- 編集内容は書き出し失敗で失われない。

## 初版の完了条件

1. ブラウザーでローカルのプロジェクトを開き、4つのシーンを切り替えられる。
2. テキスト、キャラクター、アプリアイコン、ストアバッジを追加・移動・拡大縮小・削除できる。
3. 保存して再度開いたとき、配置とスタイルが保持される。
4. プレビューにセーフエリアを表示でき、主要要素の重なりを確認できる。
5. 現在の動画生成パイプラインを使って、新しい24秒の動画を書き出せる。
6. v12など既存の動画・投稿文・記録を上書きしない。

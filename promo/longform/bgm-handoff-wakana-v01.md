作り方と決まりの全体は [`bgm.md`](bgm.md)。モモカの回の進め方と結果(Sonar の操作で気づいたこと)は [`bgm-handoff-momoka-v01.md`](bgm-handoff-momoka-v01.md) の「結果」。本人(リポジトリの持ち主)への説明・質問・報告は、日本語の平易な文で。

## やってほしいこと

1. 本人と一緒に、Sonar の**新規作成の画面で**、名前 `wakana-stage-bgm-v01`・**テンポ 88**・48kHz・24bit を先に決めてプロジェクトを作る(`D:\Cakewalk Projects\wakana-stage-bgm-v01\`)。MIDI を読み込み、テンポが 88 のままかを確かめる(読み込みでテンポが変わることがある。`bgm.md` 1.5 章)。`guide.mp4` を動画トラック(「オーディオデータも読み込む」は外す)、`guide-audio.wav` を参考トラックに、どちらも 0 秒に置く。
2. 音源の割り当てと仕上げは本人が行う。**これまでの曲の音色は使わない**: ミツバ(Warm Pad・Mellow EP・Glockenspiel)、アカネ(Dry・Soft Sine Bass・Rock・Retro Pick Bass・Overdriven Power Chord・Axe Lead Guitar)、シズク(Lofi Hop・Acoustic Bass Legato・Felt Piano・Flute)、モモカ(HOT Pop・House Bass・Nova Pluck・80s Square Lead)。穏やかなアコースティックの音色(ブラシや打楽器の柔らかいキット、丸いエレキベース、ナイロンかアコースティックのギター、カリンバかマリンバ)から選ぶ。強いリミッターはかけない。
3. 本人が WAV を書き出したら、決まり(`bgm.md` の 3 章: 48kHz・24bit・ステレオ、ピーク -1 dBFS 以下、-16 LUFS 前後、頭に無音なし)に合うかを確かめる。長さは **118 秒以上**。ピークが 0 を超えたら音量を下げる。曲の音量は -16 LUFS に近づける。
   ```
   wsl -d Ubuntu -- bash -lc "cd ~/test/parry-break && python3 promo/longform/check_bgm.py '/mnt/d/Cakewalk Projects/wakana-stage-bgm-v01/Audio Export/<書き出した>.wav' --length 117.8"
   ```
   合格したら、同じコマンドに `--to-flac promo/assets/bgm/wakana-stage-bgm-v01.flac` を付けて FLAC にする(既存は上書きしない)。
4. `promo/assets/bgm/README.md` の 2 つめの表に 1 行足す。

これまでの回で分かった注意(詳しくはモモカ・シズクの「結果」):
- 書き出す前に、トラックビューの選択を解除する(Ctrl+Shift+A)。選択があると書き出し範囲が「タイム選択範囲」になり、中身の無い WAV ができる。範囲は「プロジェクト全体」を選び直す。参考音のトラックはミュートする。
- 書き出しのビット数の既定が 32 Bit になっていることがある。24bit に直す。
- テンプレートを「No Tracks or Buses」にするとマスターのバスが無いので、音量は音源トラックの音量で合わせる。
- 音源を足すと、MIDI トラックの出力先が最初の音源のままになることがある。トラックを展開して、出力先を 1 つずつ選び直す。

## 結果(デスクトップアプリのセッションが書く)

- 日付: 2026-11-24
- できた FLAC: `promo/assets/bgm/wakana-stage-bgm-v01.flac`(`promo/assets/bgm/README.md` の 2 つめの表にも 1 行足した)
- テンポ・長さ・ピーク・音量(`check_bgm.py` の出力): テンポ 88、長さ 122.557 秒(本編 117.8 秒)、ピーク -1.4 dBFS、-16.6 LUFS、頭の無音 0.00 秒。「決まりに合っています」
- 書き出しの設定と、変換したならその内容: Sonar の書き出しで Wave・ステレオ・48000Hz・24bit(既定が 32 Bit だったので直した)・プロジェクト全体(1:01:000〜45:04:720)。変換はしていない。参考音のトラックはミュートし、選択を解除してから書き出した。リミッターはかけていない。テンプレートは「No Tracks or Buses」なので、音量は音源トラックの音量で合わせた。6 回書き出して合わせた:
  - 1 回目(全部 0dB): -19.1 LUFS・ピーク -2.7。
  - ドラムを上げるとピークがすぐ超えた(ピークはカリンバの無い章にも散らばっていて、ドラムが決めている)。そこでドラムは下げ、ベースとギターを上げた。
  - 最後: Brush -1.7dB・Jazz Bass +4.3dB・Nylon Guitar +4.3dB・Kalimba +1.3dB で合格。
  - フェーダーの上限は +6dB(7 を入れても受け付けない)。
  - 同じ設定でも書き出すたびに 0.5dB ほど音量が変わることがあった(音源の鳴り方が毎回少し違うらしい)。そのため、ピークは -1.4 と少し余裕を持たせた。
- DAW のプロジェクトの場所と、割り当てた音源: `D:\Cakewalk Projects\wakana-stage-bgm-v01\wakana-stage-bgm-v01.cwp`。音源は Sonar 付属の BandLab 音源で、これまでの曲の音色とは重ならない。Percussion=Brush(Drum Kits)、Bass=Jazz Bass(Electric Basses)、Guitar=Nylon Guitar(Guitars)、Lead=Kalimba(Percussion)。トラックは MIDI の 4 つ + 参考音 1 つ(Guide audio (mute on export))+ 音源 4 つ + 動画。MIDI を読み込んだあともテンポは 88.00 のままだった。動画は「オーディオデータも読み込む」を外して読み込んだ(117.79 秒)。
- 気になった点・CLI のセッションへの申し送り:
  - Claude には音が聞こえないので、4 つの音源の音量メーターが動くことと、書き出した WAV の数値しか確かめていない。聞こえ方は本人が聞いて決めてほしい。特に Brush のキットで、シェイカー(70)・タンバリン(54)・サイドスティック(37)が GM 配置どおりに鳴っているかが分からない。
  - 替える候補: ドラム=General MIDI Percussion(Percussion の中。GM 配置どおりに鳴るはず)・Ballad・Jazz、ベース=Electric Bass Legato・'62 P-Bass、ギター=Acoustic Guitar・12 String Guitar、リード=Marimba・Vibraphone。
  - 音源を足すと、MIDI トラックの出力先が最初の音源(1-Brush 1)のままになった(ドラム以外の 3 つ)。トラックを展開して、出力先を 1 つずつ選び直した。
  - 曲の長さは 122.6 秒で、本編(117.8 秒)より 4.8 秒長い。最後の和音の残りなので、混ぜるときにフェードしてほしい。
  - この資料と MIDI は git に入っていなかったので、ワークツリーではなくメインの作業場所のファイルを使い、README と結果欄もメイン側に書いた。

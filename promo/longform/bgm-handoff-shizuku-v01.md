## やってほしいこと

1. 本人と一緒に、Sonar の**新規作成の画面で**、名前 `shizuku-practice-bgm-v01`・**テンポ 80**・48kHz・24bit を先に決めてプロジェクトを作る(`D:\Cakewalk Projects\shizuku-practice-bgm-v01\`)。MIDI を読み込み、テンポが 80 のままかを確かめる。`guide.mp4` を動画トラック、`guide-audio.wav` を参考トラックに、どちらも 0 秒に置く。
2. 音源の割り当てと仕上げは本人が行う。**ミツバ(Warm Pad・Mellow EP・Glockenspiel)とアカネ(Rock・Retro Pick Bass・Overdriven Power Chord・Axe Lead Guitar)の音色は使わない。** ピアノは、エレピではなく生ピアノ系(柔らかいもの)。ローファイらしさを足したければ、軽いローパスやテープ風の揺れを本人と相談して付けてよい(強いリミッターはかけない)。
3. 本人が WAV を書き出したら、決まり(`bgm.md` の 3 章: 48kHz・24bit・ステレオ、ピーク -1 dBFS 以下、-16 LUFS 前後、頭に無音なし)に合うかを確かめる。長さは **126 秒以上**。ピークが 0 を超えたらマスターを下げる。曲の音量は -16 LUFS に近づける。
   ```
   wsl -d Ubuntu -- bash -lc "cd ~/test/parry-break && python3 promo/longform/check_bgm.py '/mnt/d/Cakewalk Projects/shizuku-practice-bgm-v01/Audio Export/<書き出した>.wav' --length 125.2"
   ```
   合格したら、同じコマンドに `--to-flac promo/assets/bgm/shizuku-practice-bgm-v01.flac` を付けて FLAC にする(既存は上書きしない)。
4. `promo/assets/bgm/README.md` の 2 つめの表に 1 行足す。

## 結果(デスクトップアプリのセッションが書く)

- 日付: 2026-11-19
- できた FLAC: `promo/assets/bgm/shizuku-practice-bgm-v01.flac`(`promo/assets/bgm/README.md` の 2 つめの表にも 1 行足した)
- テンポ・長さ・ピーク・音量(`check_bgm.py` の出力): テンポ 80、長さ 128.812 秒(本編 125.2 秒)、ピーク -2.3 dBFS、-15.5 LUFS、頭の無音 0.00 秒。「決まりに合っています」
- 書き出しの設定と、変換したならその内容: Sonar の書き出しで Wave・ステレオ・48000Hz・24bit・プロジェクト全体(1:01:000〜43:04:720)。変換はしていない。参考音のトラックはミュートして書き出した。リミッターはかけていない。新規作成の画面で名前・テンポ 80・24bit・48000 を先に決め、テンプレートは「No Tracks or Buses」にしたので、マスターのバスは無く、各音源トラックが直接出力に出ている。そのため音量は音源トラックの音量で合わせた: 1 回目(全部 0dB)は -20.0 LUFS・ピーク -6.3、全部 +4dB で -18.4 LUFS・ピーク -1.0、最後にベース 0dB・ピアノ +4dB・笛 +5dB・ドラム +4.5dB で合格。ピークは 12 秒ごと(Dsus2 の小節の頭、ベースの低い D)に出ていたので、ベースだけ上げていない。
- DAW のプロジェクトの場所と、割り当てた音源: `D:\Cakewalk Projects\shizuku-practice-bgm-v01\shizuku-practice-bgm-v01.cwp`。音源は Sonar 付属の BandLab 音源で、ミツバ・アカネ(v01・v02)の音色とは重ならない。Drums=Lofi Hop(ドラムキット)、Bass=Acoustic Bass Legato(Strings の中のウッドベース)、Piano=Felt Piano、Flute=Flute(Winds)。トラックは MIDI の 4 つ + 参考音 1 つ + 音源 4 つ + 動画。MIDI を読み込んだあともテンポは 80.00 のままだった。動画(`guide.mp4`)は「オーディオデータも読み込む」を外して読み込み、音は `guide-audio.wav` を別トラック(Guide audio (mute on export))に 0 秒から置いた。
- 気になった点・CLI のセッションへの申し送り:
  - Claude には音が聞こえないので、各音源の音量メーターが動くことと、書き出した WAV の数値しか確かめていない。混ぜたあとの聞こえ方や、ローファイらしさが足りるか(ローパスやテープ風の揺れを足すか)は、本人が聞いて決めてほしい。音源を替える候補: ドラム=Chill Wave・Brush、ベース=Soft Sine Bass(ただしアカネ v01 で使った)、ピアノ=Lofi Piano・Upright Piano、笛=Pan Flute。
  - 途中で 1 回、ドラム音源に隣の「Latin」を間違えて入れたので、トラックとシンセラックの両方から消した。プロジェクトには残っていない。
  - 書き出しの前にトラックビューに選択範囲があると、書き出し範囲が「タイム選択範囲」に変わり、ソースのチェックが外れて、中身の無い 4KB の WAV ができた。書き出す前に選択を解除する(Ctrl+Shift+A)とよい。
  - Sonar のコンソールで音量の値を打ち込むとき、ピアノのトラックだけ入力が確定しないことがあった(ピアノを +4dB のままにした理由)。
  - マーカーは打っていない(手順に無かったため)。
  - Edit の道具はワークツリーのセッションからメイン側のファイルを編集できないので、README と結果欄は Bash で書いた。

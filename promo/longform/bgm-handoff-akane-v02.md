# アカネの通常尺の BGM: デスクトップアプリのセッションへの引き継ぎ v02

## なぜ作り直すか

v01 を本編に混ぜて本人が聞いたところ、**ミツバの BGM と似ている**と感じた。たたき台が同じ作り(パッド・エレピ・鉄琴、同じリズムの形)だったため。本人が選んだ方向は **ロック寄り**。負けず嫌いで熱いアカネに合わせる。

## 使うもの

| もの | 場所(リポジトリの中) | 中身 |
|---|---|---|
| MIDI のたたき台 | `promo/assets/bgm/midi/akane-endless-bgm-v02.mid` | **テンポ 120**(1 小節 = 2 秒)、68 小節 = 136 秒。マーカー入り。4 トラック: Drums(ロックのキット、GM 配置・チャンネル 10。タム 41〜50 とライド 51 も使う)/ Bass(ピック弾きのエレキベース)/ Guitar(歪んだギターのパワーコード)/ Lead(歪んだギターかシンセのリード。オープニング・フィーバー・エンディングだけ) |
| 本編の見本 | `promo/build/out/akane-full-e003/bgm-kit/guide.mp4` | BGM なしの本編(声とゲーム音入り)。音だけは `guide-audio.wav`。**書き出しには入れない** |
| マーカー表 | 同じフォルダの `cues.md` | 章の始まり・まとめて崩れる・フィーバー開始の時刻と小節:拍 |

和音は A5 → G5 → D5 → A5 の繰り返し。ギターは根音と 5 度だけ(パワーコード)なので、ゲームの BGM とぶつからない D・E・G・A に収まっている。音を足すときも、この 4 音から選ぶ。

区切り(小節): オープニング 1〜5 / 01 6〜17 / 02 18〜29 / 03 崩す 30〜36(36 小節目はフィーバーへのスネアの連打)/ 03 フィーバー 37〜46 / 04 47〜57 / エンディング 58〜66 / 最後の和音 67〜68。

## やってほしいこと

1. 本人と一緒に、Sonar で新しいプロジェクト `D:\Cakewalk Projects\akane-endless-bgm-v02\` を作り、MIDI を読み込む。
   - **テンポを手で 120 にする**(v01 のとき、MIDI を読み込んでもテンポが 120 → 112 にならなかった。今回は 120 なので偶然合うが、必ず確かめる)。
   - `guide.mp4` を動画トラック、`guide-audio.wav` を参考トラックに、どちらも 0 秒に置く。
2. 音源の割り当てと仕上げは本人が行う。**ミツバの曲(Warm Pad・Mellow EP・Glockenspiel)と同じ音色は使わない。** ロックのドラム、エレキベース、歪んだギターを選ぶ。Sonar 付属の音源に歪んだギターがなければ、ノコギリ波のシンセにディストーションをかけたものでもよい(本人と相談)。
3. 本人が WAV を書き出したら、決まり(`bgm.md` の 3 章: 48kHz・24bit・ステレオ、ピーク -1 dBFS 以下、-16 LUFS 前後、頭に無音なし)に合うかを確かめる。長さは **134 秒以上**。
   - v01 ではマスター 0dB でピークが 0 を超えたので、マスターを下げて書き出した。今回もピークを見て下げる。ただし、**曲の音量は -16 LUFS に近づける**(v01 は -20.8 LUFS で小さかった)。強いリミッターはかけない。
   - 確かめる道具:
     ```
     wsl -d Ubuntu -- bash -lc "cd ~/test/parry-break && python3 promo/longform/check_bgm.py '/mnt/d/Cakewalk Projects/akane-endless-bgm-v02/Audio Export/<書き出した>.wav' --length 133.7"
     ```
   - 合格したら、同じコマンドに `--to-flac promo/assets/bgm/akane-endless-bgm-v02.flac` を付けて FLAC にする(既存は上書きしない)。合わないときは、まず Sonar の書き出しの設定を直す。直せないときは、本人に聞いてから変換で合わせる。何をしたかを「結果」に書く。
4. `promo/assets/bgm/README.md` の 2 つめの表に 1 行足す(v01 の行は残す)。

## やらないこと

- 動画の書き出し・台本・声(CLI のセッションが行う)。
- MIDI の作り直し(要るときは「結果」に理由を書く)。

## 結果(デスクトップアプリのセッションが書く)

- 日付: 2026-11-18
- できた FLAC: `promo/assets/bgm/akane-endless-bgm-v02.flac`(`promo/assets/bgm/README.md` の表にも 1 行足した。v01 の行は残してある)
- テンポ・長さ・ピーク・音量(`check_bgm.py` の出力): テンポ 120、長さ 135.875 秒(本編 133.7 秒)、ピーク -2.1 dBFS、-16.6 LUFS、頭の無音 0.00 秒。「決まりに合っています」
- 書き出しの設定と、変換したならその内容: Sonar の書き出しで Wave・ステレオ・48000Hz・24bit・プロジェクト全体。変換はしていない。マスターを -3dB にして 1 回で合格(リミッターはかけていない)。参考音(`guide-audio.wav`)のトラックはミュートして書き出した。プロジェクトは最初から 48kHz・24bit で作った(v01 は 44.1kHz・16bit だった)。
- DAW のプロジェクトの場所と、割り当てた音源: `D:\Cakewalk Projects\akane-endless-bgm-v02\akane-endless-bgm-v02.cwp`(v01 のプロジェクトは残してある)。音源は Sonar 付属の BandLab 音源で、ミツバ・v01 の音色とは重ならない。Drums=Rock(ドラムキット)、Bass=Retro Pick Bass、Guitar=Overdriven Power Chord、Lead=Axe Lead Guitar。歪んだギターは BandLab に入っていたので、ノコギリ波のシンセ+ディストーションは使っていない。トラックは MIDI の 4 つ + 参考音 1 つ + 音源 4 つ。テンポは MIDI を読み込んだあとも 120.00 のままで合っていることを確かめた(新規作成の画面で最初から 120 にしておいた)。
- 気になった点・CLI のセッションへの申し送り:
  - 本人と一緒に聴きながら決めたわけではない(デスクトップアプリのセッション(Claude)には音が聞こえない)。各音源から音が出ていること(再生中の音量メーターが動くこと)と、書き出した WAV の数値しか確かめていない。混ぜたあとの聞こえ方や「ミツバと似ていないか」は、本人が聞いて決めてほしい。気に入らなければ、音源を替える(Hard Rock・Classic Rock のドラム、Metal Guitar・Overdriven Guitar など)余地がある。
  - マーカーは打っていない(v02 の手順に無かったため)。必要なら `cues.md` の表に合わせて打てる。
  - Sonar の新規作成の画面で名前・テンポ・ビット数・サンプルレートを決めると、v01 のときのようなフォルダの二重入れ子やテンポのずれが起きない。次回もこの方法がよい。
  - Edit の道具は、ワークツリーのセッションからはメイン側のファイルを編集できないので、README と結果欄は Bash で書いた。

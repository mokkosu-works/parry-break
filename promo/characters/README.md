# キャラクター素材

5 人は Mokkosu Works の 5 人組ユニット **MOKO'5(モコズ)**。読みは「モコズ」に固定(経緯と書き方は [profiles.md](profiles.md) の冒頭)。

- `sheets/color_roster.png`: 採用した色別一覧。左からアカネ、シズク、モモカ、ワカナ、ミツバ。今後のキャラクター制作は、この画像の絵柄・配色・目のハイライトを基準にする。
- `sheets/old/character_sheet_v2.png`: 旧ミツバの表情・ポーズ集(投稿済みの v009〜v012 で使った。今は使わない)。
- `sheets/<名前>_sheet.png`(アカネ・シズク・モモカ・ワカナ・ミツバ): 性格に合わせた各キャラクターの表情・ポーズ集。左から通常、集中、予想外、失敗、成功、固有の6種類。
- 人柄・口調・セリフ例と各枠の演技指針は [profiles.md](profiles.md) を参照。
- 声の採用方針、指定クレジット、利用条件の確認状況は [voice-licenses.md](voice-licenses.md) を参照。声は AivisSpeech で、ミツバ＝花音、アカネ＝中2、シズク＝zonoko、モモカ＝るな、ワカナ＝まい(調整値は `promo/editor/render.py` の `VOICE_PROFILES`)。
- 通常尺のための話し方・ゲームとの関係・5 人の関係は profiles.md の後半、出来事ごとの反応集は [reactions.md](reactions.md)(どちらも案)。

線の太さは元のミツバの表情シートを基準にし、太い黒縁を避ける。色別一覧もこの基準に合わせて修正済み。

採用版のミツバは道具を持たず、手の仕草で表現する。`sheets/old/character_sheet_v2.png` は旧動画の再現用として残し、新規制作には `sheets/mitsuba_sheet.png` を使う。旧シートと新シートは表情の順番が異なるため、既存プロジェクトの画像だけを差し替えない。

旧一覧と旧個別シートは整理済み。Git 管理されていた旧素材は履歴から参照できる。

## 通常尺用のバストアップ(`bust/`)

通常尺(横長の解説・実況)で、口パクと目パチをしながら表情を変えるための素材。1 人 12 表情。

- `bust/<名前>_bust_sheet{1,2,3}.png`: Codex で作った元のシート(4 列 × 2 段。上の段が口を閉じた顔、下の段が口を開けた顔)。`<名前>_bust_blink.png` は目を閉じた顔。指示文は `promo/design/codex/longform-akane/ref/`(アカネ)と `longform-bust/ref/`(ほかの 4 人)。
- `bust/<名前>/<表情>_{closed,open}.png`、`normal_blink.png`: `python3 promo/longform/bust.py <名前>` で作る。画像生成では口の閉じ・開きの絵が完全には揃わず、そのまま切り替えるとちらつくので、口を閉じた絵を土台に、開いた絵の口のまわりだけを位置を合わせて貼っている(目パチも同じく目のまわりだけ)。どのファイルも同じ大きさで、同じ位置に置けば揃う。
- 表情の名前(シートの並び順)と中身:

## 全身の口パク・目パチ(`sheets/<名前>/`、2026-11-17 に本人が決定)

全身の絵は、ショートと通常尺で共通にする。土台はショート用の 6 ポーズのシート `sheets/<名前>_sheet.png`(並びは 通常・集中・予想外・失敗・成功・固有)。これに口パク・目パチを足し、ショートも通常尺も同じ絵を使う。

- `sheets/<名前>/closed.png`・`open.png`・`blink.png`: 元のシートと同じ 2172×724 で、全ポーズが「口を閉じた」「口を開いた」「目を閉じた」版。不透明な部分の形は元と同じなので、ショートの「輪郭で分離」(`editor/sprites.py`)で元と同じ位置・大きさに切り出される。`regions.json` に、ポーズごとの口・目・顔の範囲と位置合わせの結果を残す。
- 元の絵は、閉じ・開きのどちらか片方としてそのまま使い、もう片方の口だけを合成する。目を閉じたポーズ(成功の笑顔・ウインク)は目パチを作らない(`blink.png` のそのポーズは `closed` と同じ)。
- 作り方: `promo/design/codex/sheets-face/run.sh <名前>` で、Codex に「口だけを反対の状態にしたシート」と「目だけを閉じたシート」を作らせる(指示文は同じ場所の `ref/prompt-<名前>-{mouth,blink}.txt`、モデルは `gpt-6.1-terra`、参考画像は必ず生成に渡す)。次に `python3 promo/longform/sheet_face.py <名前>` で合成する(範囲はキャラ×ポーズの表 `CHARS`。範囲の外やアルファが変わったら止まる。既存の出力は上書きしない)。
- 確認画像: `design/checks/<名前>-sheet-face-v01.png`。

| ポーズ | ミツバ | アカネ | シズク | モモカ | ワカナ |
|---|---|---|---|---|---|
| 0 通常 | ○笑み / 目パチ | ○歯を見せる / 目パチ | ○ / 目パチ | ●笑顔 / 目パチ | ○ / 目パチ |
| 1 集中 | ○ / 目パチ | ○ / 目パチ | ○ / 目パチ | ○ / 目パチ | ○ / 目パチ |
| 2 予想外 | ●小さな「お」/ 目パチ | ●「お」/ 目パチ | ●小さな「お」/ 目パチ | ●「お」/ 目パチ | ●小さな「お」/ 目パチ |
| 3 失敗 | ○涙 / 目パチ | ○食いしばり / 目パチ | ○ / 目パチ | ○「×」の口 / 目パチ | ●小さく開く / 目パチ |
| 4 成功 | ●笑い / 目を閉じている | ●笑い / 目を閉じている | ○ / 目パチ | ●ウインク / なし | ○ / 目を閉じている |
| 5 固有 | ●指さし / 目パチ | ○歯を見せる / 目パチ | ○ / 目パチ | ○照れ / 目パチ | ○にやり / 目パチ |

○=元の絵が口を閉じている、●=開いている。予想外の閉じは、驚いた顔のまま口を小さくすぼめる。失敗の開きは、残念そうなまま口を開ける。

**通常尺の場面とポーズ**(全員共通。背景はショートと同じキャラの色): オープニング=通常(しゃべる)、章の区切り=固有(章のタイトルを読む。字幕は出さない。長さはタイトルに合わせ、前後の間はタイトルの前 1.5 秒・後 1.0 秒。2026-11-17 に本人が変更)、エンディング=成功(しゃべる)。本編はバストアップ。

**ショート**: キャラのレイヤーの「口パク・目パチ」(`talk: true`)を入れると、台詞の声に合わせて口を開閉し、話していない間にまばたきする(`editor/render.py` の `face_windows`)。話していない間は口を閉じた絵になる(元の絵が口を開けているポーズでも)。

**進み具合**: 5 人とも作成済みで、本人が確認済み(2026-11-17)。ショート 10 本のプロジェクトは、キャラのレイヤーに `talk: true` を入れた。
- シートで目パチがうまくいかなかったポーズ(アカネとモモカの固有)は、1 体だけ作り直した `design/codex/sheets-face/out/<名前>_blink_special.png` を使う(指示文は `ref/prompt-<名前>-blink-special.txt`)。崩れの原因は、生成した目の位置のずれと、目の範囲の下端が浅かったこと。
- シズクの予想外は、生成した「閉じた口」が元の小さな「お」とほぼ同じで、口の動きが小さい(気になれば、そのポーズだけ作り直す)。

- 確認動画: `python3 promo/longform/full_preview.py <名前> --voice-only --out <未使用の出力先>` のあと、`--voice-only` を外して同じコマンド。オープニング(通常)・章の区切り(固有)・エンディング(成功)の 3 場面で、全身と顔の拡大を並べる(本番の画面構成ではない)。最初だけ AivisSpeech(10101)が要る。確認動画は `build/out/mitsuba-full-preview-e005/` と `build/out/{akane,shizuku,momoka,wakana}-full-preview-e003/`(仮の台詞は `full_preview.py` の `CHARS`)。ショートの試し書き出しは `build/out/mitsuba-modes-talktest-e001.mp4` と `akane-modes-talktest-e001.mp4`。
